# תוכנית עבודה משימתית — הפיכת ה-Push Notifications למערכת עובדת בפועל

מטרה: לצאת ממצב "קוד קיים" למצב "הוכח שזה עובד". כל משימה כוללת: מה לעשות, מי אחראי (מפתח/DevOps/QA), ומה ה-Definition of Done (DoD) — בלי הוכחה בפועל המשימה לא נסגרת.

---

## 🔴 קריטי — לפני הכול

### משימה 1: פריסת הפונקציה העדכנית
- [ ] הפק diff בין `send-fcm-notification` הפרוס לקוד המקומי
- [ ] פרוס מחדש: `supabase functions deploy send-fcm-notification`
- [ ] ודא מספר גרסה עלה, JWT verification פעיל
- [ ] הרץ קריאת טסט בודדת, ודא ה-payload כולל `deepLink` והגבלת קואצ'ים

**DoD:** גרסה חדשה בפרודקשן, diff = 0 מול הריפו.

### משימה 2: אימות Firebase credentials בפועל
- [ ] ודא קיום `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`, `FIREBASE_PROJECT_ID` ב-Supabase secrets
- [ ] ודא ב-Firebase Console: FCM API מופעל, ל-service account יש הרשאת שליחה
- [ ] הרץ את חילופי ה-OAuth בפועל וקבל access token תקף

**DoD:** קוד תגובה 200 עם access token אמיתי מתועד. אם 401/403 — לתקן (private key/role/project ID) ולחזור על הבדיקה עד הצלחה.

## 🟡 רישום מכשירים אמיתיים

### משימה 3: טוקן Android אמיתי
- [ ] בנה/התקן build שכולל את `google-services.json` הנוכחי על מכשיר Android פיזי
- [ ] התחבר כ-Coach, אשר הרשאת התראות
- [ ] ודא שורה חדשה ב-`push_tokens` עם `platform: android`

**DoD:** שורת טוקן אמיתית בטבלה, משויכת ל-user_id נכון.

### משימה 4: טוקן iOS אמיתי
- [ ] בנה/חתום את האפליקציה עם Push Notifications capability
- [ ] ודא APNs מוגדר גם ב-Apple Developer וגם ב-Firebase
- [ ] התקן על **מכשיר iPhone פיזי** (לא סימולטור)
- [ ] אשר הרשאת התראות, ודא רישום טוקן

**DoD:** שורת טוקן iOS אמיתית בטבלה.

### משימה 5: טוקן Web אמיתי
- [ ] בדפדפן נתמך (Chrome/Edge), אשר הרשאת התראות
- [ ] ודא רישום מוצלח של ה-Service Worker
- [ ] ודא שורת טוקן web בטבלה

**DoD:** שורת טוקן web אמיתית בטבלה.

## 🟢 ההוכחה האמיתית — טסט E2E

### משימה 6: טסט מכשיר סגור (Owner → Coach)
- [ ] Coach: מפעיל התראות, סוגר את GymTrack לגמרי, נועל מסך
- [ ] Owner: שולח broadcast "כל הקואצ'ים" עם טקסט ייחודי לזיהוי (`PUSH_TEST_<תאריך>`)
- [ ] תעד: האם ההתראה הופיעה על המסך הנעול? תוכן תואם? הקשה פותחת את האפליקציה?
- [ ] בדוק בלוגים: הפונקציה דיווחה הצלחה (לא `sent: 0`)

**DoD:** צילום מסך/וידאו של ההתראה על מסך נעול + לוג הצלחה תואם. **בלי זה, שום דבר אחר בתוכנית לא נחשב "עובד".**

### משימה 7: טסט ריבוי מכשירים
- [ ] אותו Coach מחובר משני מכשירים (למשל Android + Web)
- [ ] שולחים broadcast נוסף, שני המכשירים סגורים

**DoD:** שני המכשירים קיבלו את ההתראה באותה שליחה.

### משימה 8: טסט בקרה (Realtime מול Push אמיתי)
- [ ] שולחים פעם אחת עם טאב פתוח, פעם אחת עם מכשיר סגור לגמרי

**DoD:** מכשיר סגור מקבל התראת OS אמיתית — לא רק כשה-app פתוח.

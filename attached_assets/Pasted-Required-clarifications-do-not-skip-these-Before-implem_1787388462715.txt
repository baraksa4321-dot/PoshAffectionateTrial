Workout Exercise Card — exact UX requirement

The exercise display during a workout should be redesigned as follows:

1. Exercise header
    * Exercise name
    * Replace / החלפה action
    * Rest time, for example Rest 90 sec
2. Planned values
    * Clearly display planned weight and rep range.
    * Example:
        60 kg · 8–12 reps
3. Sets
    * Display each set clearly:
        Set 1 ✓
    * Provide actual weight input.
    * Provide actual reps input.
    * Actual weight/reps should be visually smaller and more compact than the planned values.
4. Rep range
    * Rep range must be a real range, not just a single number.
    * Example: 8–12 reps
    * Support fixed reps and range reps.
    * Persist repType, repMin, and repMax.
    * Verify that the displayed range survives Save → Refresh → Logout → Login.

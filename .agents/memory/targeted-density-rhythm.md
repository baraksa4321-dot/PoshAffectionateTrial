name: Targeted density rhythm
description: Compact spacing changes must be scoped to the coach builder/report and not applied to the shared app shell.
---

Compact spacing belongs to the coach workout builder and its report drawer, not to the shared shell.

**Why:** A global chrome and spacing override made the personal home dashboard feel cramped while leaving the intended builder/report hierarchy insufficiently targeted.

**How to apply:** Add a route or state-specific page class for builder mode, keep the home dashboard's approved rhythm intact, and reduce report internals independently from global cards and navigation.
